# Security

Report vulnerabilities via GitHub Security Advisories:

https://github.com/jonheaven/yard/security/advisories/new

Do not file a public issue for key-material or mainnet-consignment bugs
until the advisory exists. Review of the public spec still belongs in
GitHub issues, not DMs.

There is no bounty token, no points, and no airdrop for reports.

Never send funded WIFs, RPC passwords, or mainnet `.yard` files.
Regtest vectors that use the spec throwaway scalar (`...0001`) are fine.
